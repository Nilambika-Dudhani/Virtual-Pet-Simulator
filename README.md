# 🐾 Virtual Pet Simulator

## 📖 Overview

Virtual Pet Simulator is a Python command-line application that allows users to take care of a virtual pet. The user can interact with the pet by feeding it, playing with it, and checking its status. The pet's happiness and hunger levels change based on the user's actions, creating an engaging simulation of pet care.

This project was developed to practice core Python programming concepts such as functions, loops, conditional statements, dictionaries, and user interaction.

---

## ✨ Features

* 🍖 Feed the pet to reduce hunger
* 🎾 Play with the pet to increase happiness
* 📊 Check the pet's current status
* ⏳ Automatic time progression system
* 😢 Hunger affects the pet's happiness
* 💀 Game-over conditions
* 🔄 Menu-driven interactive interface
* 📝 Pet information stored using dictionaries

## 🎮 How the Simulator Works

The pet starts with:

* Happiness Level = 50
* Hunger Level = 50

### Feed Pet

* Decreases hunger level
* Slightly decreases happiness

### Play With Pet

* Increases happiness level
* Slightly increases hunger

### Check Status

Displays:

* Pet Name
* Happiness Level
* Hunger Level
* Current Mood

### Automatic Changes

As time passes:

* Hunger gradually increases
* Happiness gradually decreases

### Game Over Conditions

The simulation ends if:

* Hunger reaches 100
* Happiness reaches 0
